# Community conduct

Treat participants with respect. No harassment, discrimination, threats, doxxing or publishing private information. Give actionable technical feedback and respect decisions within the documented governance process.

Maintainer: @CompleteDotTech. Report conduct concerns privately using the contact method published on the maintainer's GitHub profile. If no private contact method is published, request a private channel without including sensitive details. Do not post sensitive details publicly. Maintainers may remove abusive content, limit participation and document proportionate enforcement while protecting reporters' privacy.
