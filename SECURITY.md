# Security policy

No application release is currently supported; the repository is a planning and engineering foundation.

Report vulnerabilities privately through this repository's GitHub **Security → Report a vulnerability** feature when enabled. If unavailable, contact the maintainer through the contact method published on the actual GitHub profile https://github.com/CompleteDotTech before disclosing details. Do not post secrets, exploit details or private board data in public issues. A dedicated response SLA and security mailbox have not been established.

Include affected revision, reproduction, impact and redacted evidence. Maintainers should acknowledge, assess tenant/credential impact, coordinate a fix and disclosure, and document affected releases. Never claim an independent security review or production security certification without linked evidence.

Release gates require threat model review, authorization negative tests, dependency/license review, upload/import defenses, secret checks and actual independent security review. Production secrets belong outside source and images; rotate on suspected disclosure.
