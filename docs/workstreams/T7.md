# T7: User Interface & Accessibility

Owner expertise: UX & Accessibility. No individual assignment implied.

## Research question

Define supported Discord viewport/client matrix and practical accessibility alternatives for canvas interactions.

## Required contract

Specify responsive shell, focus order, accessible controls, save/error states and visual design tokens.

## Capability scope

### Activity shell

- **Responsive board navigation and toolbar**: Build Discord-compatible board switcher, drawing toolbar and participant display; adapt to desktop and mobile available space; keep current board and role visible.

- **Settings, themes and permission indicators**: Expose guild/board settings according to permission; implement dark/light tokens, clear edit restrictions, mode indicators and accessible permission explanations.

### Async feedback

- **Loading, save status and errors**: Distinguish local pending edits, durably saved revision, reconnecting and failed state; provide retry/recovery actions without falsely reporting save success.

- **Moderation controls and request feedback**: Display pending drawing requests, grant expiry and revoke feedback; avoid optimistic privilege grants; keep focus stable after moderator decisions.

### Input and accessibility

- **Keyboard navigation and focus**: Define keyboard shortcuts without Discord collisions; trap/restore modal focus, expose visible focus and accessible names; provide keyboard alternatives for moderation and board navigation.

- **Screen readers, touch and reduced motion**: Provide meaningful non-canvas controls and announcements; verify touch targets, contrast and reduced-motion settings; document accessible limitations and supported alternatives.

### UI assurance

- **Component integration and responsive tests**: Exercise loading, forbidden, offline, empty and large-content states using role-aware fixtures; verify layout and touch behavior at supported viewport sizes.

- **Accessibility acceptance and remediation**: Run automated accessibility checks plus manual keyboard and screen-reader scenarios; track canvas limitations and blocking defects with reproducible evidence.
