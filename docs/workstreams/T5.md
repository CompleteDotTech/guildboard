# T5: Boards, Persistence & Recovery

Owner expertise: Data Engineering. No individual assignment implied.

## Research question

Evaluate MySQL/MariaDB transaction, snapshot, asset storage and retention strategy for VPS crash recovery and board scale.

## Required contract

Define tenant-scoped schema, migration safety, durable acknowledgment, snapshot cut and restore lineage contracts.

## Capability scope

### Board lifecycle

- **Guild-owned boards and channel defaults**: Create, list and select boards with guild-scoped visibility; support rename, duplication and channel defaults; prohibit cross-guild references and copy assets safely.

- **Archive, restore and deletion safeguards**: Implement reversible archive and explicit deletion confirmation with access checks; define soft-delete retention, purge policy and stale socket behavior; record lifecycle audit events.

### Durable storage

- **MySQL/MariaDB schema and migrations**: Create tenant-scoped board, member policy, operations, snapshots, assets and audit tables with constraints/indexes; test clean install, upgrade and failed migration recovery.

- **Operation persistence and autosave**: Commit authorized operation, deduplication receipt and revision atomically; emit durable acknowledgments only after commit; expose save status and recover from database timeout without false success.

### History and recovery

- **Snapshots, version history and checkpoints**: Create snapshots at consistent revision boundaries; expose authorized history and named checkpoints with audit attribution; compact logs only after safe snapshot and backup retention conditions.

- **Restore operations and crash recovery**: Restore as a new audited revision/lineage; fence active writers and preserve recoverable previous state; recover snapshot plus operation tail and verify integrity after forced crash.

### Assets and portability

- **Asset uploads and storage**: Store uploads outside web root under opaque tenant-scoped IDs; validate type, decoded size and quotas; reject active content/path traversal; authorize reads and clean orphaned assets safely.

- **Import/export and retention**: Provide versioned export/import of board and asset references with limits; validate untrusted files; apply documented privacy retention, data deletion and database integrity checks.
