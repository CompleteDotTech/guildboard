# T8: Backend APIs & Discord Commands

Owner expertise: Backend & Bot. No individual assignment implied.

## Research question

Verify least-privilege bot installation, slash-command permissions and API surface needed by Activity administration.

## Required contract

Specify Fastify routes, shared validation/error envelopes, auth middleware, OpenAPI and versioned WebSocket contracts.

## Capability scope

### Backend foundation

- **Fastify routing and shared contracts**: Compose modular routes and typed request/response schemas; expose versioned API; validate input before side effects and use consistent error envelope with request ID.

- **Authentication and authorization middleware**: Resolve server session, tenant and policy once per request with freshness checks; enforce route action permissions and object scope; prevent body parameters overriding authenticated context.

### Product APIs

- **Board, guild and moderation routes**: Implement scoped board CRUD, channel defaults, role mappings, requests, grants and locks; enforce idempotency for retried actions and consistent audit records.

- **Asset and export routes**: Authorize scoped upload/download/export/import; bound streaming size and resource use; validate content disposition and prevent arbitrary path resolution.

### Discord bot

- **Bot installation and slash registration**: Document least-privilege install flow and command registration lifecycle; separate development guild and production rollout; verify interactions and avoid secrets in registration logs.

- **Board, permission and lock commands**: Provide authorized board selection/linking, permission inspection and lock/unlock commands; verify guild context and ephemeral error handling; reject unauthorized or cross-guild invocation.

### API compatibility

- **OpenAPI and contract versioning**: Generate OpenAPI from shared schemas; publish WebSocket message version compatibility policy; reject unknown breaking versions and maintain migration notes.

- **API and bot integration acceptance**: Test all endpoints/commands with invalid sessions, malformed input, wrong guild, insufficient roles, Discord failures and database rollback; compare documented and implemented contracts.
