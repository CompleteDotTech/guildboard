# T3: Whiteboard Canvas & Editing

Owner expertise: Frontend & Canvas. No individual assignment implied.

## Research question

Evaluate pinned Excalidraw API for element identity, controlled changes, undo, assets, accessibility, touch and custom moderated editing.

## Required contract

Define canonical element/mutation schema, editor adapter boundaries, supported tools and revision-aware undo contract.

## Capability scope

### Canvas adapter

- **Excalidraw integration and rendering**: Wrap pinned editor behind an adapter; preserve stable element identifiers and schema versions; render infinite canvas and hydrate validated state without treating UI callbacks as authorized server writes.

- **Editor state serialization and migrations**: Serialize elements, app state and asset references with size limits; exclude ephemeral identity and tokens; validate schemas and support explicit migration or safe rejection of incompatible imports.

### Drawing tools

- **Freehand, eraser, shapes and connectors**: Support pen, eraser, shapes, arrows and connectors with bounded geometry; preserve bindings and reject malformed coordinates; synchronize edits through canonical operations.

- **Text, sticky notes and styling**: Support text and sticky-note representation with font/style controls; sanitize text and external links; document missing native editor behavior and required custom extensions.

### Object operations

- **Selection, transforms, groups and layers**: Support selection, movement, rotation, resize, grouping and layer ordering; express multi-element changes atomically; preserve connector relationships and ownership constraints.

- **Copy/paste and revision-aware undo/redo**: Validate clipboard input and remap identifiers; prevent resurrection of forbidden/deleted elements; undo only accepted local intent without overwriting another editor's subsequent changes.

### Navigation and performance

- **Zoom, pan, touch and stylus**: Support viewport navigation and pointer pressure where available; distinguish touch drawing from navigation; validate stylus behavior and minimum target sizes on supported Discord clients.

- **Read-only canvas and rendering budgets**: Disable local editing affordances for viewers while keeping navigation; require server denial of forged writes; measure agreed large-board render budgets, memory and interaction latency.
