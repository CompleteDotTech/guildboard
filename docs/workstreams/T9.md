# T9: Security, Privacy & Abuse Prevention

Owner expertise: Security Engineering. No individual assignment implied.

## Research question

Threat-model Discord iframe, OAuth, tenant isolation, authoritative edits and public VPS attack surface; prioritize abuse scenarios.

## Required contract

Specify security controls, privacy inventory, retention/deletion policy, audit integrity and release security evidence.

## Capability scope

### Identity and tenant security

- **OAuth, sessions and credential handling**: Review code exchange, replay, session fixation, token exposure and secret rotation; validate CSRF/origin controls appropriate to chosen auth transport; prohibit secrets in source, logs and exports.

- **Privilege escalation and tenant isolation**: Prove route/socket/object authorization denies foreign guild identifiers, forged roles, stale grants and moderator-to-admin escalation; add negative test for each critical boundary.

### Content and input defenses

- **XSS, SQL injection and path traversal**: Validate and parameterize database input; sanitize imported text/URLs; prohibit arbitrary filesystem paths and unsafe rendering; define and test Discord-compatible content security policy.

- **Upload and resource abuse protection**: Enforce decoded file limits, content type checks, quotas and safe storage; test polyglots, oversized payloads, decompression bombs, message floods and slow clients.

### Privacy and audit

- **Retention, deletion and privacy disclosure**: Inventory Discord identifiers, board content, assets, logs and backups; define purpose/access/retention; implement deletion propagation and explain backup retention exceptions.

- **Audit integrity and incident evidence**: Protect audit records from ordinary writers and moderators; record security events without tokens or unnecessary content; define access control, integrity checks and evidence preservation.

### Security assurance

- **Dependency auditing and security automation**: Run dependency, secret and static analysis checks with triaged findings; record exceptions with expiry conditions; verify lockfile provenance and license obligations.

- **Independent security review and release gate**: Obtain an actual independent review of auth, tenancy, imports, replay and VPS exposure; remediate findings and retain evidence; block release on unresolved critical/high risk without accepted disposition.
